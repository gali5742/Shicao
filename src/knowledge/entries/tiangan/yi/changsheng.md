乙为阴干，十二长生自**午**起逆行[[cite:yi-changsheng-seq]]：

| 状态 | 地支 |
|---|---|
| 长生 | 午 |
| 沐浴 | 巳 |
| 冠带 | 辰 |
| 临官 | 卯 |
| 帝旺 | 寅 |
| 衰 | 丑 |
| 病 | 子 |
| 死 | 亥 |
| 墓 | 戌 |
| 绝 | 酉 |
| 胎 | 申 |
| 养 | 未 |

乙**长生于午**。乙以木之形质论，午月枝叶繁盛，因此以午为乙之长生[[cite:yi-changsheng-life]]。

乙至**亥为死**。亥月枝叶剥落，木之外在形质随之凋落，因此以亥为乙之死地[[cite:yi-changsheng-death]]。
