丁为阴干，十二长生自**酉**起逆行[[cite:ding-changsheng-seq]]：

| 状态 | 地支 |
|---|---|
| 长生 | 酉 |

| 冠带 | 未 |
| 临官 | 午 |
| 帝旺 | 巳 |
| 衰 | 辰 |
| 病 | 卯 |
| 死 | 寅 |
| 墓 | 丑 |
| 绝 | 子 |

| 养 | 戌 |

丁**长生于酉**。酉时四阴司权，有“**灯火则能辉煌，列星则能灿烂**”之说，故说丁火生于酉[[cite:ding-changsheng-life]]。

丁至**寅为死**。寅地三阳当合，阳火而生、阴火而退，可取日出而列星隐耀、灯光不显之象，说明丁火至寅渐退[[cite:ding-changsheng-death]]。
