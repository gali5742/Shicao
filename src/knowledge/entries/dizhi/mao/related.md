### 与十二长生

十二长生以地支为配位。十天干运行至卯位时，分别处于以下状态[[cite:mao-related-1]]：

| 天干 | 在卯所处状态 |
|---|---|
| 甲 | 帝旺 |
| 乙 | 临官 |
| 丙 | 沐浴 |
| 丁 | 病 |
| 戊 | 沐浴 |
| 己 | 病 |
| 庚 | 胎 |
| 辛 | 绝 |
| 壬 | 死 |
| 癸 | 长生 |

这些状态表示各天干运行至卯位时的十二长生配属。

### 禄与羊刃

卯也是部分天干的禄、羊刃配属位置：

- **乙禄在卯**[[cite:mao-related-2]]；
- **甲刃在卯**[[cite:mao-related-2]]。

### 与六十甲子

天干与地支依固定次序相配。卯与阴干相配，在六十甲子中形成：

**乙卯、丁卯、己卯、辛卯、癸卯。**[[cite:mao-related-3]]
