### 与十二长生

十二长生以地支为配位。十天干运行至亥位时，分别处于以下状态[[cite:hai-related-1]]：

| 天干 | 在亥所处状态 |
|---|---|
| 甲 | 长生 |
| 乙 | 死 |
| 丙 | 绝 |
| 丁 | 胎 |
| 戊 | 绝 |
| 己 | 胎 |
| 庚 | 病 |
| 辛 | 沐浴 |
| 壬 | 临官 |
| 癸 | 帝旺 |

这些状态表示各天干运行至亥位时的十二长生配属。

### 禄与羊刃

亥也是部分天干的禄、羊刃配属位置：

- **壬禄在亥**[[cite:hai-related-2]]；
- **癸刃在亥**[[cite:hai-related-2]]。

### 与六十甲子

天干与地支依固定次序相配。亥与阴干相配，在六十甲子中形成：

**乙亥、丁亥、己亥、辛亥、癸亥。**[[cite:hai-related-3]]
