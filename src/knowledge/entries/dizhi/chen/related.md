### 与十二长生

十二长生以地支为配位。十天干运行至辰位时，分别处于以下状态[[cite:chen-related-1]]：

| 天干 | 在辰所处状态 |
|---|---|
| 甲 | 衰 |
| 乙 | 冠带 |
| 丙 | 冠带 |
| 丁 | 衰 |
| 戊 | 冠带 |
| 己 | 衰 |
| 庚 | 养 |
| 辛 | 墓 |
| 壬 | 墓 |
| 癸 | 养 |

这些状态表示各天干运行至辰位时的十二长生配属。

### 与六十甲子

天干与地支依固定次序相配。辰与阳干相配，在六十甲子中形成：

**甲辰、丙辰、戊辰、庚辰、壬辰。**[[cite:chen-related-2]]
