### 与十二长生

十二长生以地支为配位。十天干运行至丑位时，分别处于以下状态[[cite:chou-related-1]]：

| 天干 | 在丑所处状态 |
|---|---|
| 甲 | 冠带 |
| 乙 | 衰 |
| 丙 | 养 |
| 丁 | 墓 |
| 戊 | 养 |
| 己 | 墓 |
| 庚 | 墓 |
| 辛 | 养 |
| 壬 | 衰 |
| 癸 | 冠带 |

这些状态表示各天干运行至丑位时的十二长生配属。

### 与六十甲子

天干与地支依固定次序相配。丑与阴干相配，在六十甲子中形成：

**乙丑、丁丑、己丑、辛丑、癸丑。**[[cite:chou-related-2]]
