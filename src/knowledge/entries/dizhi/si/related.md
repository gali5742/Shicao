### 与十二长生

十二长生以地支为配位。十天干运行至巳位时，分别处于以下状态[[cite:si-related-1]]：

| 天干 | 在巳所处状态 |
|---|---|
| 甲 | 病 |
| 乙 | 沐浴 |
| 丙 | 临官 |
| 丁 | 帝旺 |
| 戊 | 临官 |
| 己 | 帝旺 |
| 庚 | 长生 |
| 辛 | 死 |
| 壬 | 绝 |
| 癸 | 胎 |

这些状态表示各天干运行至巳位时的十二长生配属。

### 禄与羊刃

巳也是部分天干的禄、羊刃配属位置：

- **丙禄在巳**[[cite:si-related-2]]；
- **戊禄在巳**[[cite:si-related-2]]；
- **丁刃在巳**[[cite:si-related-2]]；
- **己刃在巳**[[cite:si-related-2]]。

### 与六十甲子

天干与地支依固定次序相配。巳与阴干相配，在六十甲子中形成：

**乙巳、丁巳、己巳、辛巳、癸巳。**[[cite:si-related-3]]
