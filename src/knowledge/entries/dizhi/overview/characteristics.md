十二地支在传统文献中常被解释为一年气机由萌发、生长、成熟到收藏的连续过程。

这些解释并不完全一致。例如《释名》以“子孳、丑纽、寅演、卯冒”等说明时序变化；《五行大义》又保存“寅者移也，亦云引也”等不同训释[[cite:overview-characteristics-1]][[cite:overview-characteristics-2]]。它们共同表现的是十二支与四时气机之间的联系，而不是一套唯一的文字字源解释。

下面列出一组有代表性的传统解释：

| 地支 | 传统训释举例 | 所表现的时序状态 |
|---|---|---|
| 子 | 孳 | 阳气开始萌生 |
| 丑 | 纽 | 萌生之气屈结、续长 |
| 寅 | 演、引 | 生气展开，引物而出 |
| 卯 | 冒 | 万物冒土而出 |
| 辰 | 伸、震 | 万物伸舒、震动而长 |
| 巳 | 已、起 | 阳气布散，生长进一步展开 |
| 午 | 仵 | 阴阳之气相交相逆 |
| 未 | 昧、味 | 万物渐向成熟 |
| 申 | 身 | 形体渐成 |
| 酉 | 秀 | 万物成实、收成 |
| 戌 | 恤、灭 | 万物转入收敛衰落 |
| 亥 | 核、阂 | 万物收藏、闭藏 |

这些训释用于理解十二地支在时序循环中的位置，不应直接改写为现代人格性格。
