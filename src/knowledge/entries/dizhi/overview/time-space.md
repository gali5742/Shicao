### 月建与节气

十二地支与十二月建相配。

月令的转换以节气中的“节”为界，而不是以农历初一为界。《千里命稿·地支篇》逐支以“月令、月节、月气”列出这一关系[[cite:overview-time-space-1]]。

| 地支 | 月序 | 月节 | 中气 |
|---|---|---|---|
| 寅 | 正月 | 立春 | 雨水 |
| 卯 | 二月 | 惊蛰 | 春分 |
| 辰 | 三月 | 清明 | 谷雨 |
| 巳 | 四月 | 立夏 | 小满 |
| 午 | 五月 | 芒种 | 夏至 |
| 未 | 六月 | 小暑 | 大暑 |
| 申 | 七月 | 立秋 | 处暑 |
| 酉 | 八月 | 白露 | 秋分 |
| 戌 | 九月 | 寒露 | 霜降 |
| 亥 | 十月 | 立冬 | 小雪 |
| 子 | 十一月 | 大雪 | 冬至 |
| 丑 | 十二月 | 小寒 | 大寒 |

这种配属使地支成为传统月令体系的重要组成部分。

### 十二支方位

十二地支依次环列一周，子居正北，自子位起顺时针依次排列[[cite:overview-time-space-2a]][[cite:overview-time-space-2b]]。

子、午、卯、酉分别居正北、正南、正东、正西，为十二支四正。

按十二支环周位置作现代方向表达时，可进一步细分为：

| 地支 | 方位 |
|---|---|
| 子 | 正北 |
| 丑 | 东北偏北 |
| 寅 | 东北偏东 |
| 卯 | 正东 |
| 辰 | 东南偏东 |
| 巳 | 东南偏南 |
| 午 | 正南 |
| 未 | 西南偏南 |
| 申 | 西南偏西 |
| 酉 | 正西 |
| 戌 | 西北偏西 |
| 亥 | 西北偏北 |

十二支方位与五行方位有关，但二者不能简单等同。例如辰、戌、丑、未都属土，却各自在十二支环周中占有不同位置；不能因为“土”在五行方位中常与中央相关，就把四支都理解成同一个空间位置。

《三命通会·十二支分配地理》即在具体讨论各支时，同时使用其方位和五行说明传统取象[[cite:overview-time-space-3]]。

### 十二时辰

十二地支还用于表示一日十二时。《三命通会》称“**昼夜十二时均分百刻**”[[cite:overview-time-space-4]]。

按现代钟点常用折算[[cite:overview-time-space-5]]：

| 地支 | 现代钟点 |
|---|---|
| 子 | 23:00—01:00 |
| 丑 | 01:00—03:00 |
| 寅 | 03:00—05:00 |
| 卯 | 05:00—07:00 |
| 辰 | 07:00—09:00 |
| 巳 | 09:00—11:00 |
| 午 | 11:00—13:00 |
| 未 | 13:00—15:00 |
| 申 | 15:00—17:00 |
| 酉 | 17:00—19:00 |
| 戌 | 19:00—21:00 |
| 亥 | 21:00—23:00 |

子时跨越现代日期的23时至次日1时。术数排盘如何确定日界，属于时间计算规则，并不是地支“子”本身的固有性质。
