### 与十二长生

十二长生以地支为配位。十天干运行至申位时，分别处于以下状态[[cite:shen-related-1]]：

| 天干 | 在申所处状态 |
|---|---|
| 甲 | 绝 |
| 乙 | 胎 |
| 丙 | 病 |
| 丁 | 沐浴 |
| 戊 | 病 |
| 己 | 沐浴 |
| 庚 | 临官 |
| 辛 | 帝旺 |
| 壬 | 长生 |
| 癸 | 死 |

这些状态表示各天干运行至申位时的十二长生配属。

### 禄与羊刃

申也是部分天干的禄、羊刃配属位置：

- **庚禄在申**[[cite:shen-related-2]]；
- **辛刃在申**[[cite:shen-related-2]]。

### 与六十甲子

天干与地支依固定次序相配。申与阳干相配，在六十甲子中形成：

**甲申、丙申、戊申、庚申、壬申。**[[cite:shen-related-3]]
