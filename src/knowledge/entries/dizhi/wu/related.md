### 与十二长生

十二长生以地支为配位。十天干运行至午位时，分别处于以下状态[[cite:wu-related-1]]：

| 天干 | 在午所处状态 |
|---|---|
| 甲 | 死 |
| 乙 | 长生 |
| 丙 | 帝旺 |
| 丁 | 临官 |
| 戊 | 帝旺 |
| 己 | 临官 |
| 庚 | 沐浴 |
| 辛 | 病 |
| 壬 | 胎 |
| 癸 | 绝 |

这些状态表示各天干运行至午位时的十二长生配属。

### 禄与羊刃

午也是部分天干的禄、羊刃配属位置：

- **丁禄在午**[[cite:wu-related-2]]；
- **己禄在午**[[cite:wu-related-2]]；
- **丙刃在午**[[cite:wu-related-2]]；
- **戊刃在午**[[cite:wu-related-2]]。

### 与六十甲子

天干与地支依固定次序相配。午与阳干相配，在六十甲子中形成：

**甲午、丙午、戊午、庚午、壬午。**[[cite:wu-related-3]]
