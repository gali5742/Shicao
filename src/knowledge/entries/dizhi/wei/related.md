### 与十二长生

十二长生以地支为配位。十天干运行至未位时，分别处于以下状态[[cite:wei-related-1]]：

| 天干 | 在未所处状态 |
|---|---|
| 甲 | 墓 |
| 乙 | 养 |
| 丙 | 衰 |
| 丁 | 冠带 |
| 戊 | 衰 |
| 己 | 冠带 |
| 庚 | 冠带 |
| 辛 | 衰 |
| 壬 | 养 |
| 癸 | 墓 |

这些状态表示各天干运行至未位时的十二长生配属。

### 与六十甲子

天干与地支依固定次序相配。未与阴干相配，在六十甲子中形成：

**乙未、丁未、己未、辛未、癸未。**[[cite:wei-related-2]]
