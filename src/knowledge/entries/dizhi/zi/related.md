### 与十二长生

十二长生以地支为配位。十天干运行至子位时，分别处于以下状态[[cite:zi-related-1]]：

| 天干 | 在子所处状态 |
|---|---|
| 甲 | 沐浴 |
| 乙 | 病 |
| 丙 | 胎 |
| 丁 | 绝 |
| 戊 | 胎 |
| 己 | 绝 |
| 庚 | 死 |
| 辛 | 长生 |
| 壬 | 帝旺 |
| 癸 | 临官 |

这些状态表示各天干运行至子位时的十二长生配属。

### 禄与羊刃

子也是部分天干的禄、羊刃配属位置：

- **癸禄在子**[[cite:zi-related-2]]；
- **壬刃在子**[[cite:zi-related-2]]。

### 与六十甲子

天干与地支依固定次序相配。子与阳干相配，在六十甲子中形成：

**甲子、丙子、戊子、庚子、壬子。**

其中甲子居六十甲子之首，与“甲为干首，子为支初”的次序相应[[cite:zi-related-3]]。
