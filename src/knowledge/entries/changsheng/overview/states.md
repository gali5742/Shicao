十二长生借万物由发生、成长、成熟、衰退、收藏到重新萌生的过程说明十二种状态[[cite:cs-states-1]]。

| 状态 | 基本含义 |
|---|---|
| **长生** | 万物发生向荣，开始生长 |
| **沐浴** | 又称“败”，始生而形体柔脆 |
| **冠带** | 万物渐渐荣秀 |
| **临官** | 万物既已秀实，渐趋成立 |
| **帝旺** | 万物成熟而盛 |
| **衰** | 盛极之后形气渐衰 |
| **病** | 衰退进一步发展 |
| **死** | 生长过程趋于终尽 |
| **墓** | 又称“库”，成功之后归于收藏 |
| **绝** | 又称“受气”，前一循环已尽，新的形象尚未显现 |
| **胎** | 阴阳之气交感，开始受胎萌生 |
| **养** | 万物已经成形，仍处于孕育之中 |

墓之后又进入绝、胎、养，继而重新长生。因此，“死”“墓”“绝”都处在整个循环之中，并非循环的最终终点。
