# 参考资料格式规范 v0.1

本规范固定知识库前台“参考资料”的基础显示方式。来源数据保持结构化保存，由统一 formatter 生成前台文字；知识正文和组件不得自行拼接参考文献字符串。

## 1. 古籍

基本格式：

```text
《书名·篇名》
```

例如：

```text
《尚书·洪范》
```

若需要进一步定位到篇内章节、条目或段落，由 citation 的 `locator` 追加：

```text
《尚书·洪范》，五行
```

如果篇名已经是来源结构的一部分，不得再次把同一篇名作为 locator 重复显示。因此不使用：

```text
《尚书·洪范》 · 洪范
```

## 2. 现代专著

基本格式：

```text
作者：《书名》，出版社，年份
```

需要精确位置时，由 citation 的 `locator` 追加页码或章节。

## 3. 论文

基本格式：

```text
作者：《文章名》，《期刊名》，年份期次，页码
```

## 4. 引用归属

参考资料原则上挂在实际使用它的 section 或 relation 上，不因为某本书与整个知识条目“有关”就统一显示。

因此：

- “基本概念”只显示该选项卡实际参考的资料；
- “基本性质”只显示该选项卡实际参考的资料；
- “相关关系”只显示相应关系数据实际引用的资料；
- 当前选项卡没有引用资料时，不显示空的“参考资料”区域。

## 5. 数据与显示分离

来源数据保存为 `KnowledgeSource` 的结构化字段；前台通过 `formatKnowledgeCitation()` 统一生成显示文字。以后调整格式时，只修改 formatter，不批量改写知识条目。
