# v0.1.2 实施记录

本轮根据五行详情页审查意见调整知识模型与前台结构。

## 主要修改

- 新增 `wuxing.overview`，使“五行”本身成为可独立访问的知识条目；分类页通过 `overviewEntryId` 引用概说，同时不把概说混入木、火、土、金、水五张分项卡片。
- `KnowledgeEntry` 增加可选 `pinyin` 字段，详情标题与分类卡片可显示拼音。
- 移除木、火、土、金、水的“木行/火行……”机械别名。`aliases` 继续保留，但只用于确有阅读价值的既有异名，例如后续“偏印 / 枭神”这一类关系到术语体系的别名。
- “相关关系”并入详情页选项卡，与“基本概念”“基本性质”使用同一切换逻辑。
- 参考资料改为跟随当前选项卡：section 使用自己的 citations；relation 也支持自己的 citations；当前内容没有引用时不显示参考资料区。
- 新增统一参考文献 formatter。古籍《尚书》中的《洪范》现由结构化字段 `title: 尚书` + `partTitle: 洪范` 生成 `《尚书·洪范》`，不再出现 `《尚书·洪范》 · 洪范` 的重复格式。
- 新增 `docs/REFERENCE_FORMAT_v0.1.md`，固定古籍、现代专著、论文的第一版显示规则。
- Validator 增加分类概说条目和 relation citation 的引用检查。
- 静态审计从 5 个分项条目调整为 1 个五行概说 + 5 个分项条目，共 6 个 entry。

## 前台原则进一步固定

- 内部 ID、分类 ID、source ID 等仍不显示给读者。
- 字段存在不等于必须展示；没有有意义别名时不显示“别名”行。
- 参考资料必须对应当前正在阅读的内容，而不是笼统附在整个条目下。
- 拼音属于知识数据，不在组件中手写。
