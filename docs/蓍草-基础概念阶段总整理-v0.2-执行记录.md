```text
阴阳 ─┐
```

补充：

- **旺相休囚死**：五行 × 四时时令。
- **十二长生**：五行层可论整体生旺墓；十干层进一步分阴阳顺逆。
- **三合**：取五行层的长生、帝旺、墓（库）。
- **三会（方合）**：取同一方位三支一气联贯。

# 三、全局统一口径

## 1. 六十甲子

统一以：

> **六十甲子**

为主名；“六十花甲子”为异称。

所有天干、地支旧稿中的：

> 与六十花甲子

统一改为：

> **与六十甲子**

正文中的“在六十花甲子中形成……”统一改为：

> **在六十甲子中形成……**

父级《干支纪序》保留“六十甲子，也称六十花甲子”的说明。

---

## 2. 旺相休囚死与十二长生

两套体系严格分层：

### 旺相休囚死

- 主体：五行；
- 参照：四时时令；
- 同一五行的阴阳干状态相同；
- 不采用阳顺阴逆。

### 十二长生

- 主体：五行整体／十干；
- 参照：十二地支配位；
- 十干采用阳顺阴逆；
- “旺”“死”等同名术语不得与旺相休囚死直接等同。

---

## 3. 三合

统一口径：

- 三合是四组固定三支组合；
- 以五行层的**长生、帝旺、墓（库）**解释生、旺、库；
- 不在基础《三合》条目讨论半合、拱合、不完整组合及成局条件；
- 数据层必须保存完整三个成员，不拆成普通二元关系。

---

## 4. 三会（方合）

前台与正文统一显示：

> **三会（方合）**

核心解释：

> 三会也称方合，是十二地支之间四组依方位形成的三支组合关系，可以“三支一气联贯”理解其结构。

---

## 5. 禄、羊刃

- 不再作为共同基础概念顶层条目。
- 《禄》《羊刃》以后进入命理知识层。
- 现有天干／地支页面中的禄刃信息属于下游配属，可暂保留，但应避免让目录层级误导为八字、六爻共同底层规则。

## B. 地支概述

地支概述此前承担了过多完整事实表。现已建立《藏干》及六种地支关系独立条目，因此概述应压缩为“整体框架”，避免重复维护。

### 1. “藏干与人元”建议替换为

```markdown
## 藏干与人元

地支内部另有藏干结构，支中所藏天干也常称“人元”。

藏干说明一个地支内部包含哪些天干；人元司事则进一步讨论月令内部不同时段由哪些气用事。两者彼此相关，但并不是同一层次。
```

完整十二支藏干表、子月壬癸司事等内容统一由《藏干》条目承担。

### 2. “地支关系”建议替换为

```markdown
## 地支关系

地支之间除五行生克外，还存在六合、六冲、相刑、相害、三合与三会（方合）等固定关系与组合。

其中六合、六冲、相害主要表现为二支关系；三合、三会（方合）以及部分相刑结构需要保留完整的多支组合与方向。

这些关系首先表示地支之间的结构联系，并不直接等同于固定吉凶结果。
```

概述不再重复六组六合、六组六冲、六组相害、三刑完整方向、四组三合、四组三会的全部表格。

## 2. 旺相休囚死

不维护 25 个独立结果。

由：

```text
当令五行
+
五行生克
```

推导：

```text
当令本身 → 旺
当令所生 → 相
生当令者 → 休
克当令者 → 囚
当令所克 → 死
```

土的时令口径另行配置，不与五行关系规则混写。

# 九、阶段结论

完成以上同步后，“基本概念”层可以视为第一阶段闭合。

后续知识体系可从共同基础向不同术数分流：

```text
共同基础
├─ 八字／四柱命理
│  ├─ 十神
│  ├─ 禄
│  ├─ 羊刃
│  └─ 后续命理结构
└─ 六爻
   ├─ 八宫
   ├─ 装卦
   ├─ 六亲
   ├─ 世应
   ├─ 用神／取用
   └─ 后续六爻结构
```

分类归属只表示主要知识层级，并不限制其他术数体系引用同一知识条目。
