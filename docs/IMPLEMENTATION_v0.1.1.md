# 术数知识库 v0.1.1 修订记录

本次修订针对首轮前台审查，不改变知识核心层的基本架构。

## 前台修订

- 五行分类页移除分类 ID 与条目 Knowledge ID 的可见输出。
- 五行条目卡片改为正常横向文字布局；宽屏五项同排，中等宽度两列，窄屏单列。
- 详情页移除 Knowledge ID 的可见输出。
- “基本概念 / 基本性质”改为真正的章节选项卡；当前只渲染被选中的正文。
- 返回链接改为面向读者的“返回五行”等文字。
- 搜索与首页删除“测试项目、独立架构、v0.1”等开发说明。
- 无效知识链接不再把内部 target ID 暴露给读者。

## 内容修订

- 删除“样板条目、验证知识引用、结构化关系数据、正式教材阶段、运行时推导”等开发语言。
- 五行摘要改为面向普通读者的简短说明。
- 十个 Markdown section 改为实际知识正文，保留《尚书·洪范》的经典表述，并自然使用内部知识链接。

## 结构保持不变

以下部分未因前台修改而耦合：

- Knowledge ID
- Registry
- Validator
- 自动发现
- 正反向关系解析
- Markdown 正文拆分
- public API
- Route Adapter

## 新增检查

新增 `tests/ui/frontend-boundary.test.ts`，用于检查：

- 前台不直接输出内部 ID；
- section tab 确实进行单选切换；
- 常见开发/测试说明不进入主要前台页面。
